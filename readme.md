## 🌙 Sobre el proyecto

**Esencia Violeta** es un espacio elegante, cálido y místico para la venta de tarot y artículos esotéricos, con un enfoque en la comunidad y el acompañamiento espiritual.

Cada mazo, cada vela y cada amuleto están elegidos con la intención de acompañarte en tu camino espiritual. Que la luna te guíe.

---

## ✨ Características

- 🃏 **Tienda de tarot** con catálogo de productos
- 🔮 **Experiencias comunitarias** para compartir historias místicas
- 📖 **Blog** con artículos sobre espiritualidad
- 🛒 **Carrito de compras** interactivo
- 🌙 **Diseño mágico** con efectos visuales únicos
